Como funciona

Sem caixa-preta. Explicamos exatamente como o modelo gera cada pick.

TL;DR — Resumo em 30 segundos

Coletamos resultados e estatísticas de cada partida das 8 ligas que cobrimos (Brasileirão, Premier League, La Liga, Bundesliga, Ligue 1, Serie A, Saudi e Argentina).

Para cada partida agendada, o modelo calcula a probabilidade de 7 mercados: resultado, ambas marcam (BTTS), gols (Over/Under), escanteios, cartões, faltas e finalizações.

Quando a probabilidade calculada é ≥ 80%, vira um "pick" e aparece no dashboard. Toda recomendação é congelada no momento da apresentação e o resultado é registrado automaticamente.

Passo a passo

1

Coleta de dados (Sofascore)

Todo dia às 9h BRT, um scraper automatizado puxa do Sofascore:

  • Placar e estatísticas dos jogos terminados (escanteios, cartões, faltas, chutes)
  • Árbitro escalado para cada partida
  • Próximas rodadas com odds de mercado

→ Histórico armazenado: ~5 anos de dados, atualizados diariamente

2

Cálculo de probabilidade

Para cada partida agendada, agregamos estatísticas dos times nas últimas N partidas. Aplicamos Bayesian shrinkage ajustando para a média da liga (evita times com poucos jogos enviesarem as previsões).

O modelo gera uma probabilidade para cada mercado:

• Over/Under X.5 gols — usa média de gols dos últimos jogos + ajuste de liga
• Vitória/Empate — usa elo rating + força como mandante/visitante
• BTTS — frequência histórica de ambas marcarem
• Escanteios/Cartões — média da partida + tendência do árbitro
3

Filtro: só ≥ 80% vira pick

Cálculos abaixo de 80% nem aparecem. O dashboard só mostra recomendações com confiança real. Divididas em 4 faixas:

🎯 95% – 100%
"Quase certo". Raríssimas (3-5/semana).
🟢 90% – 95%
"Alta confiança". ~10-15/semana.
🟡 85% – 90%
"Boa confiança". ~20-30/semana.
🟠 80% – 85%
"Confiança razoável". ~40-60/semana.
4

Congelamento (o passado não muda)

Esse é nosso compromisso mais importante. Quando um pick é apresentado a 87%, esse 87% fica registrado para sempre.

Mesmo que o modelo, em uma nova rodada, recalculasse esse mesmo jogo a 81% (porque as estatísticas dos times mudaram), o pick original não é alterado. O histórico é imutável.

→ Conceito técnico: p_original + band_hist congelados em betMeta

5

Auto-validação dos resultados

Quando um jogo termina, o sistema compara o placar real com o pick e marca automaticamente:

  • Verde — pick acertou
  • Vermelho — pick errou

O histórico de assertividade é recalculado e fica público. Nenhum pick é apagado.

⚠️ Limitações honestas

  • • Nenhum modelo é 100%. Mesmo picks 95%+ erram às vezes (5% das vezes, por definição).
  • • O modelo é estatístico, não preditivo de eventos isolados (lesões, expulsões, etc).
  • • Variância existe. Você pode ter 5 vermelhos seguidos mesmo no longo prazo positivo.
  • • Gerencie banca. Nunca aposte mais do que pode perder.
  • • Apostas envolvem risco financeiro real. Use com responsabilidade.
